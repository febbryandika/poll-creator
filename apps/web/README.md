# @poll-creator/web

The Next.js 16 web app for **poll-creator** — SSR poll pages, Better Auth, and poll CRUD via
Server Actions. It talks to the Hono real-time API (`@poll-creator/api`) for voting and live results.

This package is part of a pnpm monorepo. See the [root README](../../README.md) for setup, the
architecture overview, and how to run everything together.

```bash
pnpm --filter @poll-creator/web dev   # or `pnpm dev` from the repo root to run all apps
```
